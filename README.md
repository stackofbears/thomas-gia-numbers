This is a practice version of the Number Speed & Accuracy portion of the Thomas General Intelligence Assessment.

You'll be shown three numbers. Your job is to click the one that is farthest from the middle number. For example, if you were shown 5, 14, and 8: 8 is the middle number. 14 is farther from 8 than 5 is, so the correct answer is 14.

The top-right displays your total number of correct and incorrect answers, as well as the average time it's taken you to choose correctly so far. Checking the "Feedback" box will cause a brief pause after each answer to indicate which choice was correct.

This is a standalone page that you can run offline. Just save the HTML file and open it in your browser.

I don't make any claims about how similar this is to the actual test or even whether or not it's a useful practice tool.
